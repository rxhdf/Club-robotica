## 📝 Notación matemática común

- **Vectores**: $\vec{v}$ o $\mathbf{v}$
- **Matrices**: $A$, $B$, $X$
- **Transpuesta**: $A^T$
- **Inversa**: $A^{-1}$
- **Derivada**: $\frac{df}{dx}$ o $f'(x)$
- **Derivada parcial**: $\frac{\partial f}{\partial x}$
- **Gradiente**: $\nabla f$
- **Sumatorias**: $\sum_{i=1}^{n} x_i$
- **Productoria**: $\prod_{i=1}^{n} x_i$
