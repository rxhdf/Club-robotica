## 🔧 Instalación

### Windows
```bash
# Descarga desde python.org
# O usa Microsoft Store
python --version
```

### Linux/Mac
```bash
# Generalmente viene preinstalado
python3 --version

# Instalar pip
sudo apt-get install python3-pip  # Ubuntu/Debian
brew install python3  # macOS con Homebrew
```

### Entornos virtuales
```bash
# Crear entorno virtual
python -m venv mi_entorno

# Activar entorno
source mi_entorno/bin/activate  # Linux/Mac
mi_entorno\Scripts\activate  # Windows

# Instalar paquetes
pip install paquete_nombre
```
