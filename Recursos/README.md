# Recursos Generales

Esta carpeta contiene recursos adicionales, herramientas útiles y enlaces de referencia para complementar tu aprendizaje.

## 🛠️ Herramientas de desarrollo

### IDEs y Editores
- **Visual Studio Code**: Editor ligero y extensible
- **PyCharm**: IDE específico para Python
- **Visual Studio**: IDE completo para C++ y otros lenguajes
- **Jupyter Notebook**: Para experimentación interactiva
- **Google Colab**: Notebooks en la nube con GPU gratis

### Control de versiones
- **Git**: Sistema de control de versiones
- **GitHub**: Plataforma de alojamiento de código
- **GitLab**: Alternativa a GitHub
- **GitHub Desktop**: Cliente GUI para Git

### Línea de comandos
- **Terminal/CMD**: Interfaz de comandos
- **PowerShell**: Shell de Windows
- **Bash**: Shell de Linux/Mac
- **Oh My Zsh**: Framework para Zsh
- **Fish**: Shell interactivo y amigable

## 💡 Consejos generales

1. **Aprende haciendo**: La mejor forma de aprender es practicando
2. **Proyectos personales**: Construye cosas que te interesen
3. **Lee código de otros**: Aprende de proyectos open source
4. **Participa en la comunidad**: Comparte conocimiento y ayuda a otros
5. **Mantente actualizado**: La tecnología cambia rápidamente
6. **No te rindas**: La programación es difícil, pero vale la pena
7. **Documenta tu aprendizaje**: Escribe sobre lo que aprendes
